# ForgeKit Developer Documentation

This is a controlled public documentation fixture for the StackWatch Scrape-Verse hackathon project. ForgeKit is fictional and was created specifically for the demo.

The site is intentionally structured with predictable semantic HTML, stable class names, headings, sections, endpoints, code examples, deprecation notices, migration notes, and changelog entries to demonstrate scraper resilience.

Version 1 is the healthy scraper state. During the hackathon demo, we will intentionally change the HTML structure to trigger scraper degradation and Bright Data self-healing. DO NOT modify the HTML structure yet.

Routes: /, /authentication, /api/projects, /webhooks, /migration, /changelog.

## Run locally

Run npm install, then npm run dev. Open http://localhost:3000.
